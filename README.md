# Inventory Management System

Educational Python command-line application for managing products and stock.

## Run

Requires Python 3. No external packages are needed.

```sh
python inventory_management.py
```

## Features

- Add, view, search, update and remove products
- Receive stock and record stock withdrawals
- Show low-stock warnings and inventory totals
- Save and load inventory in CSV format

The application creates `inventory_data.csv` in the current working directory on its first run. No existing inventory data is included in this repository. This local data file is excluded from version control.
